# 🧠 Mind Plot

**Mind Plot** is a powerful all-in-one productivity app designed to help users stay organized, focused, and constantly improving. Whether you're managing tasks, tracking time, learning math and English, or handling finances — Mind Plot has the tools to keep your mind and goals aligned.

## 🚀 Features

- ✅ **To-Do List:** Organize tasks with deadlines, priorities, and categories.
- ⏱️ **Timers:** Track how long you spend on each task to improve time management.
- 💡 **Particle Simulation:** Explore basic simulations for focus or fun.
- 🧮 **Scientific Calculator:** Full-featured calculator including scientific and finance functions.
- 💸 **Finance Tools:** Track spending, calculate savings, and plan budgets.
- 🎮 **Learning Games:** Improve your Math and English skills with interactive mini-games.
